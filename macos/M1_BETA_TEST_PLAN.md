# GY 输入法 macOS M1 Beta 回归与交付清单

> 目的：本清单是 GYInput macOS 公开 Beta 的验收记录。构建或 smoke test 通过不等于应用兼容；以下每一项都必须在真实 Apple Silicon Mac 上完成并记录。

## 测试环境

每轮先记录：macOS 版本、Mac 型号、显示器/缩放、GY 版本、Rime 版本、是否为干净 macOS 用户账户，以及每个目标 App 的版本。

## 构建与测试安装

从 `macos/` 目录执行：

```bash
./scripts/configure-m1.sh
./scripts/build-macos.sh
./scripts/smoke-test-macos.sh
```

仅用于内测的未签名/临时签名 App 必须只安装到一个输入法目录。推荐当前账户目录：

```bash
./scripts/install-local-macos.sh --user
```

然后前往“系统设置 → 键盘 → 文本输入 → 编辑”，添加 **GY 拼音**。若系统没有立即列出新输入法，退出并重新登录当前账户后再检查；不要通过关闭 SIP、绕过 Gatekeeper 或伪造签名解决该问题。

机器范围测试和发布包使用 `/Library/Input Methods`。若该机已存在用户目录副本，使用
`./scripts/install-local-macos.sh --system --replace-user-copy`；不得保留两份同 Bundle ID 的 GYInput.app。先切换到系统自带输入法，才可以卸载 GY。
安装脚本会先暂存并验证新的系统 bundle，替换成功后才会把用户目录副本移到废纸篓；若中途被取消，重新运行同一命令完成更新，不要重新安装第二份用户副本。
脚本还必须在安装后清除构建目录、废纸篓副本的 LaunchServices 残留记录，确认只剩安装位置的一个 GYInput 注册记录。
安装后先运行 `./scripts/check-local-install-macos.sh`；它必须通过，才开始在系统设置中启用和跨应用回归。

## 每个应用的核心回归

| 操作 | 预期结果 |
|---|---|
| 输入 `nihao`，按空格 | 默认候选行最多 5 个词；展开后固定 5 列 × 最多 5 行。空格提交“你好”，没有拼音或 marked text 残留。 |
| 输入候选超过一页的拼音，按 `PageDown` / `PageUp` | 候选翻到对应页；数字只提交当前横向页面显示的候选。 |
| 输入候选后按 `1` 到 `5` | 对应当前第一行的候选被提交；展开的其余行仅可点选；不得错选。`6` 到 `9` 和 `0` 不得提交候选或泄漏到编辑器。 |
| 输入候选后按 `←` / `→` | 蓝色选中态在当前可见候选中移动；空格提交当前选中项。 |
| 输入候选后按 `↓` / `↑` | 不需要点击候选窗箭头。单行状态按一次 `↓` 展开固定 5 列 × 最多 5 行，选中项仍在第一行；以后每按一次 `↓`，选中项向下移动一行（+5），到第五行后进入下一 Rime 页并保持列位置。`↑` 完全反向逐行返回；回到第一页第一行后，再按一次 `↑` 收回单行。 |
| 输入候选后按 `PageDown` / `PageUp` | 翻到下一 / 上一候选页，不改变“↓ 逐行展开、↑ 顶端收起”的约定。 |
| 有预编辑但 Rime 暂无可用候选 | 仅保留 App 自己的预编辑文本；GY 候选窗必须隐藏，绝不能显示孤立的箭头、分隔线或“中”。 |
| 输入 `nihao` 后按回车 | 原样提交 `nihao`，输入模式仍为中文。 |
| 输入 `nihao` 后按 Escape、退格或切换窗口 | 预编辑和候选窗清除；不能在新窗口提交旧候选。 |
| 中文模式输入 `, . ; : / ? < > [ ] { } ' \" !` | 产生对应中文标点和成对的智能引号；有预编辑时先提交默认候选，再插入标点。 |
| 单独按 Shift | 在最近中文模式与 EN 间切换；候选窗与菜单只显示 **简**、**繁** 或 **EN**，不显示模糊的“中”。先在另一 App 的设置页切换模式再按 Shift，也必须按最新本地设置切换。Shift 与字母、数字、方向键、Tab 或其他修饰键组合不切换。 |
| EN 模式输入 | 英文字母、数字、英文标点、方向键和应用快捷键原样交给目标 App；不得开启拼音预编辑、候选窗或中文标点替换。切回简 / 繁后恢复对应中文标点与拼音。 |
| `⌘C`、`⌘V`、`⌘X`、`⌘A`、`⌘F`、`⌥` 快捷键 | 全部由目标 App 正常处理，GY 不吞键。 |
| 设置本地短语 `dz=地址` 并输入 `dz` | 本地短语置顶、可选、重启输入法后仍存在。 |
| 选择非首选 Rime 候选后重复输入 | 本地学习使该候选的排序提升，并在重启后保留。 |
| 设置 → 本地数据 → 清除学习 | 先显示确认；确认后只将 `luna_pinyin.userdb` 移到废纸篓。GY 本地短语和内置词库仍保留；注销并重新登录后，学习排序从新的本地数据库开始。 |
| 关于 → 反馈 | 打开默认邮件应用，收件人为 `contact@gsyen.com`；正文仅预填 GY 版本、macOS 版本和更新通道，不得包含输入内容、密码或个人词库。 |
| 关于 → 检查更新（内测包） | 仅请求 `https://www.shurufa.wang/download/macos-beta.json`；有新版时仅打开 HTTPS 下载页，不自动下载、替换或安装输入法。 |

## 更新、回退与卸载

1. 保持 Chrome、微信、Word 和 VS Code 打开，安装一个较新版本。
2. 不强制终止用户应用。已打开的应用可能需要重新打开或退出并重新登录后加载新的输入法 bundle；记录实际行为。
3. 在上述应用重新执行核心回归。旧版本出现问题时，切换到其他输入法后恢复上一版 bundle，再验证可正常输入。
4. 卸载前先在系统输入法菜单切换到系统自带输入法，然后删除 GY bundle：

   ```bash
   rm -rf "$HOME/Library/Input Methods/GYInput.app"
   sudo rm -rf "/Library/Input Methods/GYInput.app"
   ```

   第二条只适用于由管理员安装的版本。用户词库与设置位于 `~/Library/Application Support/GYInput`；仅在用户明确选择清除个人词库和学习数据时才删除该目录。

## 发布判定

- 构建、arm64、嵌入 librime、签名和 smoke test 均通过。
- 8 个应用矩阵全部完成，且没有未解决 P0/P1。
- 干净用户账户完成至少一次首次安装、更新、回退和卸载。
- 仅当 Developer ID Application、Developer ID Installer 和 Notary Profile 真实可用时，运行 `package-release.sh`；随后通过签名、staple、Gatekeeper 和 SHA-256 检查才可运行 `publish-r2.sh`。
