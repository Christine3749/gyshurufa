# macOS / Windows VI 与交互严格对照审核

审核分支：`codex/macos-stage4`

审核基线：`GY_INPUT_METHOD_PRODUCT_STANDARD.md`、`GY_VISUAL_IDENTITY.md`、`WINDOWS-DESIGN.md`、`SETTINGS-PANEL-DESIGN.md`

实现证据：macOS `GYInput/Sources` 与 Windows `native/src`

> 状态含义：**一致**表示两端源码实现相同契约；**平台等价**表示调用不同平台 API，但行为目标一致；**差异**表示不得按“已经对齐”验收。

## 4. 键盘与鼠标交互

| 操作 | 收起 | 展开 | Windows / macOS |
|---|---|---|---|
| `Space` | 提交当前高亮候选（默认等于本行第 1 个，`← / →` 移动后随高亮变化） | 提交高亮候选 | 一致 |
| `Enter` | 提交原始拼音 ASCII | 提交高亮候选 | 一致 |
| `1–5` | 选择当前 5 个候选 | 选择高亮所在行的第 N 列；末行缺列不误选 | 一致 |
| `↓` | 有候选即展开（不要求 >5） | 下移一行，可跨页 | 一致 |
| `↑` | 翻上一页（5 个），退到第 0 页仍第一行时不动 | 上移一行，可跨页；第一页第一行再按 ↑ 收回单行并保留高亮 | 一致 |
| `← / →` | 移动高亮候选，越过页边界循环 | 左右移动，行内不跨行（行首/行尾按住不动） | 一致 |
| `PageUp / PageDown` | 每次 5，在已取回的候选池内 clamp，不重新查询引擎 | 每次 25，同一 clamp 规则 | 一致 |
| `Esc` | 取消预编辑 | 取消预编辑 | 一致 |
| 单独按下并释放 `Shift` | 简/繁 ↔ EN | 简/繁 ↔ EN | 一致 |
| `Shift` 与其他键组合 | 不切换模式 | 不切换模式 | 一致 |
| `Cmd/Ctrl/Option` 快捷键 | 交还宿主应用 | 交还宿主应用 | 平台等价 |
| 点击候选 | 提交对应候选 | 提交对应候选 | 一致 |
| 点击展开箭头 | 展开 | 收起 | 一致 |
| 点击模式标签 | 打开设置 | 打开设置 | 一致 |
| 中式标点 | `，。？！；：`，预编辑中先提交首选 | 相同 | 一致 |

EN 模式中字母、标点、Enter 和应用快捷键原样直出；切入 EN 会取消仍在进行的中文预编辑。

## 5. 剪贴板（不是便签）

当前实现是**本机剪贴板历史**，不是可以自由编辑、创建标题或长期归档的“便签”。

| 能力 | Windows | macOS | 状态 |
|---|---|---|---|
| 自动监听文本复制 | 系统事件监听 | 0.5 秒 pasteboard 轮询 | 平台等价 |
| 最大条目 | 20 | 20 | 一致 |
| 单条上限 | 1 MiB UTF-8 | 1 MiB UTF-8 | 一致 |
| 连续重复去重 | 是 | 是 | 一致 |
| 存储格式 | `clipboard-history.tsv` | 同格式 | 一致 |
| 排序 | 最新在前 | 最新在前 | 一致 |
| 卡片正文 | 最多 4 行 | 最多 4 行 | 一致 |
| 清空二次确认 | 是 | 是 | 一致 |
| 敏感内容排除 | 支持 Windows 隐私格式标记 | 未识别来源应用的排除标记 | **差异 / 隐私待办** |
| 点击历史项重新粘贴 | 未实现 | 未实现 | 一致但未完成 |
| 跨设备同步 | 开关值可保存，传输未接入 | 开关值可保存，传输未接入 | **未完成** |
| 即时粘贴 | 开关值可保存，执行链路未接入 | 开关值可保存，执行链路未接入 | **未完成** |

因此审核时只能验收“本机历史记录与清空”，不能把跨设备同步、即时粘贴或便签功能标成已完成。
