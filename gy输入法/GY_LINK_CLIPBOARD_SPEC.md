# GY Link：跨设备剪贴板规格

## 用户承诺

三台已配对设备（Windows Pro、Windows Air、MacBook）都安装 GY 后：

1. 在任一设备复制一段文字。
2. 另外两台设备在数秒内收到该内容。
3. 用户可直接按 `Ctrl+V`（Windows）或 `⌘V`（macOS）粘贴，或从 GY 剪贴板历史选择。

这是一项 **GY Link** 能力，由常驻代理负责；输入法 TSF DLL 只通过本地 IPC 与其通信，绝不承担网络连接。

## 两种同步模式

| 模式 | 行为 | 默认值 |
| --- | --- | --- |
| 受保护同步 | 内容进入加密的 GY 剪贴板历史；目标设备通知用户，需从历史选中后才写入系统剪贴板。 | 默认开启 |
| 即时粘贴 | 目标设备收到后直接更新本机系统剪贴板，因此可立即使用 `Ctrl+V` / `⌘V`。 | 用户明确开启 |

即时粘贴只推荐用于用户本人完全信任的设备组。设置中必须显示最近同步来源和“一键暂停所有同步”。

## 第一版范围

- 纯文本、URL、HTML 富文本；最大 1 MiB。
- 最近 20 条本地历史；加密中继端的每条内容默认 24 小时过期。
- Windows 10/11 与 macOS；支持离线队列与重新连接。
- 图片、文件、屏幕截图、代码块专用格式放到第二阶段，不能阻塞文本体验上线。

## 必须排除的敏感内容

- 默认不自动同步疑似密码管理器、一次性验证码、私钥、恢复助记词和银行卡号。
- 检测到 4–10 位一次性验证码时显示“仅本机保存”；用户可以明确选择“仅这次发送”。
- 允许用户配置应用黑名单与正则规则；企业版可下发策略。
- 同步内容不得写入可上传的调试日志、分析埋点或崩溃报告。

## 安全模型

```text
设备 A 复制内容
    │ 本机捕获、分类、生成内容 ID
    ▼
GY Link Agent
    │ 端到端加密 + 设备签名
    ▼
GSYEN Relay（只保存密文、TTL 元数据）
    ▼
设备 B / C 的 GY Link Agent
    │ 验签、解密、去重、按同步模式写入历史/剪贴板
    ▼
系统剪贴板
```

- 首次配对：登录 GSYEN 账号后，通过扫码或一次性配对码确认新设备。
- 每台设备生成独立密钥对；私钥仅保存在 Windows DPAPI 或 macOS Keychain 中。
- 设备组维护一个轮换的对称内容密钥；内容使用带认证加密，密钥只加密分发给已配对设备。
- 中继服务不能读取剪贴板正文；删除设备时立即轮换设备组密钥。
- 每条内容包含唯一 ID、来源设备 ID、时间戳、格式、TTL 和签名，防重放、防篡改。

## 平台实现

### Windows

`GYLinkAgent.exe` 创建消息窗口并注册 `AddClipboardFormatListener`，接收 `WM_CLIPBOARDUPDATE`。写入远端内容时附加私有剪贴板格式 `GYLink.Origin`，监听器看到该标记后不再上传，从而避免 A → B → A 的同步循环。

### macOS

`GY Link.app` 使用 AppKit 的 general `NSPasteboard`，通过 `changeCount` 判断剪贴板内容变化。写入远端内容时添加 GY 私有 UTI 元数据，并以内容 ID 去重。macOS 自带 Universal Clipboard 不提供可供第三方操作的公开 API，因此 GY Link 维护自己的跨 Windows/macOS 加密通道。

### 共享模块

- `gy-link-core`：Rust；包含协议、端到端加密、序列化、去重和同步队列。
- Windows Agent：原生 C++/Win32 或 Rust，使用 Named Pipe 接受 TSF 与设置程序指令。
- macOS Agent：Swift/SwiftUI + AppKit，调用共享核心。
- Relay：GSYEN 后端，仅认证、路由、密文存储、过期清理和推送唤醒。

## 用户界面

- 托盘菜单：跨设备剪贴板开关、即时粘贴开关、最近三台设备、暂停、打开历史。
- 目标设备通知：`已从 MacBook 收到复制内容`，内容默认隐藏，仅显示类型和来源。
- 快捷键：`Ctrl+Shift+V` / `⌘⇧V` 打开 GY 剪贴板历史；上下选择，回车粘贴。
- 设置页：设备管理、配对新设备、同步格式、敏感内容规则、保留时长、清空本机/全部设备历史。

## 验收标准

- 三台在线设备的纯文本同步 P95 小于 2 秒。
- 飞行模式复制后，恢复网络时只同步未过期、仍被允许的内容。
- 不出现同步环、不覆盖来源设备的新复制内容、不产生重复历史。
- 关闭即时粘贴后，远端内容绝不改写本机系统剪贴板。
- 删除设备后，该设备不能读取新内容，也不能解密后续同步内容。
