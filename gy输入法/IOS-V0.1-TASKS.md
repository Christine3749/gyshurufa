# GY 输入法 iOS v0.1 施工任务拆解书

> **规范优先：** [IOS-PLATFORM-STANDARDS.md](IOS-PLATFORM-STANDARDS.md) 为 iOS 的技术、审核、隐私与无障碍硬标准；本文若有冲突，以该文件为准。

> 依据：IOS-DESIGN.md v1 · 工程原则：**质量优先于工期与体积，测试先行**（2026-08-05 产品决策）
> v0.1 目标：手感校准自微信输入法 Android 版的 26 键拼音输入法；**不请求完全访问**（系统级零联网）；
> 候选治理管线与桌面行为一致；映射层选词零错位；扩展内存全程不触顶。

---

## 一、v0.1 完成定义（DoD 总表）

**功能面**
- [ ] 26 键键盘：卡片式按键、按压加深回弹、字符气泡、上滑角标、长按变体
- [ ] 手势族完整版：删除键左滑快删 / 右滑恢复、空格/键盘面滑动移动光标、
      删除键上滑清空 / 下滑撤回——阈值与曲线以微信实测基线为准，
      且与 iOS「长按空格触控板」肌肉记忆兼容
- [ ] 拼音输入：组词、整句、组合中标点（首选+中文标点）、整句选词保留剩余拼音（只 a-z）
- [ ] 候选收起条（5 候选 + 「˅」+ 分隔线 + 模式标，GY VI 骨架）与 5 列展开面板（75 池 3 页）
- [ ] 简/EN 切换（取消预编辑不上屏、记忆中文模式）
- [ ] 密码框/验证码场景验证为系统键盘自动接管（本键盘不被调用）
- [ ] 横屏紧凑布局 + safe area（刘海/灵动岛/Home 条）适配

**质量面**
- [ ] 候选治理：无表情、无私用区、无符号、无重复、≤12 字、池上限 75
- [ ] 选词零错位（映射层单测 100% 分支覆盖）
- [ ] 扩展冷启动就绪 <300ms；按键→候选刷新 P95 <100ms；
      扩展驻留内存 <45MB 安全线（全场景遍历峰值实测入库）
- [ ] 不请求完全访问；飞行模式全流程可用

**工程面**
- [ ] CI 绿：SwiftLint 零阻断 + XCTest 门禁
- [ ] 身份字段校验脚本通过（容器 App Bundle ID / 键盘扩展 Bundle ID / App Group ID）
- [ ] 真机矩阵（iPhone SE / 标准 / Pro Max，iOS 15–18 覆盖）验收签字

## 二、任务序列（严格依赖序）

### T0 · 工程脚手架与身份契约锁
- Xcode 双 target 工程（容器 App + Keyboard Extension），代码落位仓库 `ios/`；
  工程生成工具决策（XcodeGen 或裸工程）写入 ADR
- **先锁身份字段再写业务**：容器 App Bundle ID、扩展 Bundle ID、App Group ID →
  `scripts/verify-identity.*` 校验脚本进 CI
- CI 管线（GitHub Actions macOS runner / Xcode Cloud / fastlane，T0 决策）：
  SwiftLint 零阻断 + XCTest 门禁；签名与真机部署通道
- **产出**：可安装的空键盘（系统设置能启用、能切换唤出、自绘占位键盘）
- **DoD**：CI 绿；校验脚本通过；安装/启用/唤出/切回系统键盘全流程录屏存档

### T1 · librime XCFramework（GYRimeBridge）
- 选型验证：仓输入法（Hamster）/iRime 开源集成路径 vs 自编译 XCFramework
  （device arm64 + simulator arm64）——**选型结论写成 ADR 存档**
- 桥 API（对齐 Mac GYRimeBridge 语义）：
  `init/deploy`、`processKey`、候选跨页收集（上限 75，对齐 `candidatesUpToCount:`）、
  `commitCandidateAtAbsoluteIndex`、简/繁模式切换、userdb 清空（回收站语义）
- rime-data 全量内置，与 `macos/GYInput/Resources/rime-data/` 同源同版本（构建期校验哈希）；
  首次启动 deploy 到 App Group 共享容器（版本戳增量）
- **内存与冷启动实测先行**（iOS 第一红线）：词库 mmap 加载，
  扩展驻留 <45MB 安全线、就绪 <300ms，实测数据入库
- **DoD**：扩展内测试 `nihao` → 候选含「你好」；内存/冷启动数据达标

### T2 · 候选治理管线 + 索引映射（TDD，先于一切 UI）
- **纯 Swift 模块**（不 import UIKit，可纯单测，Mac/Windows 未来可移植语义）
- 治理规则：纯 CJK 表意文字、≤12 字、滤表情/私用区/符号、去重、池上限 75
- 映射层：过滤后显示序号 → Rime 原始序号；提交只走绝对序号
- 测试先行：构造污染候选流（混入表情/重复/超长/私用区/繁体）断言过滤结果与映射一致性；
  **回归用例收录 Mac 事故词**（祢蚝/妮恏 类——过滤后选第 1 个必须提交正确词且学习加权正确）
- **DoD**：该模块单测分支覆盖 100%；不得在其测试全绿前开始 T5

### T3 · 键盘 View 体系
- **开工前置**：《手感校准基线表》键盘章节完成并入库（`ios/docs/wechat-baseline.md`：
  气泡几何与时序、按压加深时延与回弹曲线、振动档位、键位尺寸网格）
- 键位表驱动的自绘布局（数据描述键位，禁止写死坐标），26 键全键盘
- 按压瞬时加深/抬起回弹、字符放大气泡（位置与弹出时序以基线表为准，逐帧对比调）
- 主题表：浅/深/跟随系统；按键色、按压色、气泡色全部进表（§3.8 不写死）
- 键盘高度三档数据结构预留（v0.1 无设置 UI，默认标准）；横屏紧凑布局 + safe area
- **DoD**：与微信输入法同场景截图（浅/深 × 竖/横）键位、气泡、按压反馈一致；
  基线表「实测值→GY 实现值」逐项勾销

### T4 · 手势族完整版与冲突裁决
- **开工前置**：《手感校准基线表》手势章节完成并入库（快删速度曲线、恢复粒度、
  光标滑动灵敏度——位移→字符步进换算、各手势位移阈值/时间窗，同机实测）
- 手势全集：上滑角标、长按变体；删除键左滑快删/右滑恢复；
  空格/键盘面左右滑动移动光标；删除键上滑清空/下滑撤回
- **手势冲突裁决状态机**：位移阈值 / 时间窗 / 方向锁，纯 Swift 实现 + 单测，
  覆盖全集交叉冲突（例：删除键无角标语义，短上滑不触发；左滑超阈值进快删流；
  快删中反向右滑进恢复流；空格短按=空格、滑动=光标步进、长按=光标连续移动；抬手落停），
  并与「长按空格触控板」触发条件做兼容裁决
- **DoD**：裁决状态机单测全绿；四类手势与微信输入法同场景 AB 盲测，
  由非施工成员执行，手感差异可感知即不通过

### T5 · 候选条 + 展开面板
- 收起条：5 候选 + 「˅」（锚点与桌面契约同语义）+ 细分隔线 + 模式标；横滑
- 展开面板：5 列网格纵滚翻页，75 池 3 页，页码指示；**四字候选完整显示**
- 交互：点候选上屏、空格=首选、回车=原样拼音、退格逐字母回退/空预编辑透传删除
- 接入 T2 治理管线与映射层（选词提交只走绝对序号）
- **DoD**：VI 截图验收（收起/展开 × 浅/深）；污染候选流端到端选词不错位

### T6 · 键盘扩展生命周期控制器
- 预编辑生命周期；中/EN 切换（取消预编辑不上屏、记忆上次中文模式）
- **扩展回收重建**：预编辑/候选/手势态全部可重建；View 不持有已销毁 controller 引用
- `secureTextEntry`/验证码场景行为验证（系统接管，本键盘不被调用）
- 失焦/切换输入框的状态清理（预编辑、候选、手势态全复位）
- **DoD**：场景清单全过：微信聊天、Safari 地址栏、备忘录、短信验证码、WebView 表单、
  横屏视频弹幕输入

### T7 · 性能与稳定性
- 预算：扩展冷启动就绪 <300ms、按键→候选 P95 <100ms、**扩展驻留内存 <45MB 安全线**
- 遍历 30 分钟零崩溃零 jetsam；**崩溃日志审查：不含任何输入内容**（§9 红线）
- **DoD**：性能报告与崩溃-free 记录入库（后续版本回归基线）

### T8 · 验收与发布准备
- 真机矩阵：iPhone SE + 标准 + Pro Max（iOS 15–18 覆盖）
- 并排验收清单（IOS-BENCHMARK-ANALYSIS.md §四 共 7 条）逐项执行签字
- 产出营销资产：不请求完全访问的系统设置页截图、隐私清单「不收集数据」声明
- privacy manifest 齐备；TestFlight 通道；版本信息发布对接 `release/release.json` 唯一真相契约
- **DoD**：验收清单全绿；安装、升级、卸载路径各有明确结果

## 三、质量门禁（不可协商）

1. **UI 代码合入前**，其逻辑层（治理管线 / 映射 / 手势裁决 / 模式机）单测已存在且全绿。
2. SwiftLint 零阻断项；CI 不过不评审。
3. 真机矩阵不过不发布；性能预算（含内存安全线）不达标不发布。
4. 每个 T 完成时更新本文档 checkbox 与交接记录（对齐 Mac 端 MAC-HANDOFF 文档惯例）。

## 四、v0.1 明确不做（边界）

- 9 键、繁体 UI、设置四页（v0.1 无设置界面；主题跟随系统、高度默认标准，结构预留）
- 智能加空格、双击句号、首字母大写（v0.2，需设置 UI 承载开关；默认值先按微信实测默认态写死）
- GY Link、任何网络能力（v0.3；且键盘扩展永不联网，走容器 App 中继）
- 手写、语音、表情、双拼、五笔、模糊拼音（远期）
- iPad 浮动/拆分键盘（v0.4）
- **视觉资产借鉴**（色板/图标/文案/字标以 GY VI 为唯一基线，契约 §一.1a 红线）

## 五、排期提示

依赖序 T0→T1→(T2 ∥ T3)→T4→T5→T6→T7→T8；T2 与 T3 可并行。
无硬 deadline（质量优先），但每周固定产出：真机演示视频 + checkbox 更新。
