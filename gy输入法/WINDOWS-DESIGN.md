# GY 输入法 Windows 版全面设计规范（macOS 对齐基线）

> 版本：2026-08-05 · 对应 Windows 0.9.39+ 当前代码树
> 用途：macOS 端实现**一模一样体验**的施工依据。所有数值来自 `native/src/` 当前源码实测，不是设计意图。
> 上位契约：`GY_INPUT_METHOD_PRODUCT_STANDARD.md`（产品）、`gy输入法/GY_VISUAL_IDENTITY.md`（视觉）、`gy输入法/LEARNING_SEMANTICS.md`（学习语义）。冲突时以上位契约为準，本文件描述实现事实。

---

## 1. 架构总览（三层）

```text
┌─ 层① 最小不动层：GyIme.dll（TSF 文本服务，被各应用进程加载）
│    键盘接入（ITfKeystrokeMgr）、预编辑会话、文本提交、模式读取、
│    与 Host 的命名管道通讯、候选窗定位所需的文本光标测量
│
├─ 层② 可演进层：GyImeHost-<version>.exe（独立进程，托盘常驻）
│    候选窗 UI（Win32 自绘）、设置窗口、候选治理（质量门槛/学习/短语）、
│    PinyinEngine（librime 会话）、安装/健康检查
│
└─ 层③ 会员层（未建）：账户、跨设备同步、AI——独立服务，输入路径零调用
```

**进程间通讯（命名管道）：**

| 管道 | 方向 | 用途 |
|---|---|---|
| `\\.\pipe\GYInput.Host.v1` | DLL → Host | 候选查询（拼音串进、候选列表出） |
| `\\.\pipe\GYInput.Select.<session-id>` | DLL ← Host | 用户点选候选后的选择回调 |

**故障原则**：Host 崩溃时 DLL 降级为纯按键直通，不阻塞目标应用；候选查询不做阻塞 I/O（按键到候选 P95 预算 <16ms）。

## 2. 文件与部署布局

```text
C:\Program Files\GYInput\
  versions\0.9.39\

    GyImeHealth-0.9.39.exe    ← 健康检查
    rime.dll                  ← librime
    rime-data\                ← 共享 schema/词典（只读）

    GyIme.dll                 ← 层①（更新必须注销重登）

%LOCALAPPDATA%\GYInput\

  rime\                       ← Rime 用户目录（userdb 学习库）
```

注册表：TSF 注册一次，版本内不换路径不重注册。`release/release.json` 是唯一版本真相。

## 3. 输入模式

| 模式 | Mode 值 | 行为 |
|---|---|---|
| 简体 | 0 | 拼音 → 简体候选，中文标点。默认 |
| 繁体 | 1 | 拼音 → 繁体候选，中文标点。繁体只在此模式出现 |
| EN | 2 | 完全直出：不组拼音、不弹候选、不拦截任何字母/数字/标点/快捷键 |

- **单按 Shift**（按下后松开、中间无其他键）在三模式间循环中⇄EN（记住最后的中文模式）。Shift+其他键不触发切换。
- 模式全局共享：所有应用一致（经 `settings.ini [Input] Mode` + 共享内存读取）。
- 中文预编辑中切 EN：取消未确认拼音，**不偷偷上屏中文**。
- 繁/简切换在送键**之前**设置引擎选项（`zh_hans`），保证切完模式第一次按键的候选就是对的。

## 4. 按键处理全表（收起态 / 展开态）

| 键 | 收起态（单行 5 候选） | 展开态（5×5 网格） |
|---|---|---|
| a–z | 追加拼音，刷新候选 | 同左 |
| `'` (VK_OEM_7) | 追加分音节符 | 同左 |
| Space | 提交首选 | 提交高亮项 |
| 1–5 | 提交第 N 个候选 | 以高亮所在**行**为准，提交该行第 N 列；最后一行缺列不得误选 |
| Enter | 原样上屏拼音（ASCII） | 提交高亮项 |
| Esc | 取消组合 | 取消组合 |
| Backspace | 删一个字母；删空即取消 | 同左 |
| ↓ | **首次按下展开网格** | 网格内下移；页底跨页同列 |
| ↑ | 无 | 网格内上移；第一页第一行再按 ↑ 收回单行 |
| ← → | 无（透传） | 网格内左右移；页边界跨页 |
| PageUp / PageDown | 翻整页（25/页） | 同左 |
| Ctrl / Alt / Win + 任意 | 全部透传，不拦截 | 同左 |
| 中文标点 `, . ? ! ; :` | 中文模式直接输出中文标点 | 同左 |

候选窗鼠标：单击候选提交；单击右端箭头展开/收起。

## 5. 候选窗几何与定位

- 收起态：单行 **5 个**候选 + 展开箭头 + 细灰分隔线 + 模式标记（中/繁/EN），顺序锁定。
- 展开态：**5 列 × 最多 5 行 = 25/页**，75 池最多 3 页，显示 `页码/总页数`。
- 候选不足 25 只显示真实候选，**禁止假候选凑页**。
- 格子宽度：`clamp(内容自然宽度, (54+110)/2 ≈ 82, 110)`（DPI 缩放）；超长候选两遍式自然宽度布局 + 省略号兜底；四字词必须完整显示。
- 定位：贴文本光标（TSF 文本范围测量）；测量失败用 `GetGUIThreadInfo` 兜底；跨应用切换时作废旧光标位置（`last_caret_valid_` 归属标志，SetContext/Deactivate 时作废），**禁止漂移到上一个应用的位置**。
- DPI：全面板尺寸按系统 DPI 缩放，多屏移动跟随目标屏。

## 6. 候选治理管线（PinyinEngine.Lookup）

```text
Rime 扫描前 96 个原始候选
  → 质量门槛（纯 CJK 表意文字，≤12 字；过滤表情/私用区/符号/重复）
  → 前 25 进首页池，其后进深页池，合计上限 75
  → 学习注入：本编码下用户选过的词若不在池内（Rime 排名 >96 也要），
     过质量门槛 + 简繁归一后补入
  → 按学习分降序稳定排序（同分保持 Rime 原序）
  → 自定义短语过门槛 + 简繁归一后置顶
  → 去重，截断到 75
```

- 候选池是**上限不是配额**：6 个好候选就显示 6 个。
- 繁体模式只出繁体（`NormalizeOutputScript` 双向归一，含学习词和短语）。
- EN 模式 Lookup 直接返回空。

## 7. 学习系统

- 存储：`settings.ini [Learning]`，键 = `拼音→候选`，值 = 选择次数（每次选词 +1，封顶 100000）。
- 语义：见 `LEARNING_SEMANTICS.md`——学习必须能浮现（注入），不只是池内重排；学习词仍受质量门槛和简繁约束。
- 清空学习：设置窗"清空学习"按钮（删整个 [Learning] 节，不影响短语）。
- 缓存：带文件时间戳的内存缓存，多线程持锁访问。

## 8. settings.ini 完整 schema

```ini
[Input]      Mode = 0|1|2            ; 简体|繁体|EN
[Appearance] Theme = 0|1|2           ; GY蓝夜|暖白|石墨
             CandidateSize = 13|15|17; 紧凑|默认|大
[Account]    Name = <本地标识文本>    ; 邮箱等，仅存本机
[Phrases]    code = 短语1|短语2       ; 自定义短语
[Learning]   拼音→候选 = 次数         ; 学习数据
```

文件必须 UTF-16 写入；导入备份限 64 KB 并校验格式。

## 9. 设置窗口

- 入口：候选窗上打开（锚点定位，不跳位置）。Win32 自绘弹窗，`WS_POPUP` + 圆角 region，尺寸固定（默认 520×680 @96dpi，DPI 上限 136%），切页/展开短语**不改变窗口尺寸比例**。
- 四页：通用（短语管理/清空学习/导出/导入）· 输入（简/繁/EN 三段选择 + 切换规则说明）· 外观（主题卡片/字号/AI 预览助手占位）· 账户（本地标识输入框 + GY 账户占位）。
- **主题跟随**：设置窗 palette 跟随候选窗主题，点主题卡片即时整窗换色。
- **只有"完成"按钮保存**；右上角 × 直接关闭不保存。
- 账户输入框：无边框 EDIT + 父窗绘制内框 + 占位提示（EM_SETCUEBANNER）。

## 11. macOS 对齐清单

**必须一模一样（产品语义层）：**

1. 第 3 节模式行为 + Shift 契约（含"切 EN 取消预编辑不上屏"）
2. 第 4 节按键全表（产品标准 §3.3 明文：两端禁止因底层差异改变键盘契约）
3. 第 5 节 5 候选 / 5×5 / 三页 75 / 页码 / 贴光标不漂移
4. 第 6 节候选治理管线（96 扫描、质量门槛、75 池、**学习注入**——见 LEARNING_SEMANTICS.md，Mac 有原生学习直通优势，加治理层时不得退回"只重排"）
5. 第 10 节全部颜色数值（设置窗跟随主题，accent 恒定）
6. settings 存储语义（Mac 用 JSON/plist 均可，但键语义和第 8 节一一对应，便于未来同步）

**平台原生、不要求一致（实现层）：**

- 候选窗技术：第一阶段 `IMKCandidates`，之后自绘面板也要遵守第 5 节几何
- 设置窗：独立 Settings.app 或内嵌页，Mac  Human Interface 惯例
- 凭据：Keychain（对应 Windows DPAPI）
- Rime 用户目录：`~/Library/Application Support/GYInput/rime`
- 签名/公证、PKG 安装器、`/Library/Input Methods`

**Mac 当前差距清单**：见 `macos/BUG-REVIEW.md`（P0-1/P0-3 已修待真机验证；展开网格、workspace 版本戳、面板失焦隐藏等待做）。
