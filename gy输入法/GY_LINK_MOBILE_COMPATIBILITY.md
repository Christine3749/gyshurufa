# GY Link：Android 与 iOS 接入边界

> **规范优先：** [IOS-PLATFORM-STANDARDS.md](IOS-PLATFORM-STANDARDS.md) 为 iOS 的技术、审核、隐私与无障碍硬标准；本文若有冲突，以该文件为准。

## 统一目标

GY Link 的设备组覆盖 Windows、macOS、Android、iOS。所有设备用同一 GSYEN 账号、同一端到端加密设备组、同一份可撤销设备列表与同一剪贴板历史协议。

## Android：完整同步体验

用户把 GY 设为默认输入法后，`GY 输入法 for Android` 可按 Android 默认 IME 的剪贴板权限模型读取复制内容，并与桌面端一样提供受保护同步、即时粘贴、本地历史和敏感内容过滤。

产品承诺：Windows、macOS、Android 在线时，纯文本从复制到其他设备可用的 P95 小于 2 秒。

## iOS / iPadOS：主动粘贴体验

iOS 不能承诺后台静默读取每一次系统复制：系统会在没有用户意图时提示读取通用剪贴板。GY 采用合规、清晰的“主动粘贴时拉取”模式：

1. 用户打开 GY Keyboard 或 GY Link.app。
2. 点击“跨设备粘贴”。
3. GY 从端到端加密历史取得最新远端内容，并在用户当前输入位置粘贴。

因此 iOS 用户会看到同一个 GY 剪贴板历史与设备列表，但产品不承诺后台自动改写 iPhone/iPad 的系统剪贴板。用户主动打开 GY 键盘或粘贴控件后，P95 目标为 2 秒。

## 跨平台一致性

- 受保护同步默认开启；即时粘贴只允许用户明确开启。
- 密码、验证码、私钥、助记词默认不自动发送。
- 删除任一设备后轮换设备组密钥，失效设备不能读取后续内容。
- 每次同步保留来源设备、内容类型、时间与 TTL；内容正文不进入服务端日志。
