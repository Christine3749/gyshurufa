# GY 输入法 · 跨平台交互契约（Windows ↔ macOS）

> 版本：2026-08-05 · 状态：单一事实来源（single source of truth）
> 两端实现都必须逐条对上本契约；契约变更 = 两端同批变更。
> 上位文件：`SETTINGS-PANEL-DESIGN.md`、`CLIPBOARD-PAGE-DESIGN.md`、`GY_LINK_CLIPBOARD_SPEC.md`

## 0. 契约总则

1. **交互一模一样，技术各自原生**：Windows 用 TSF + 自绘 GDI 面板，macOS 用 InputMethodKit + AppKit。用户能感知的每一层（页序、文案、默认值、确认弹窗、卡片形态）两端必须逐字一致；用户感知不到的（存储格式、绘制 API）各自为政。
2. **设置即契约**：任何设置项的键、默认值、取值范围先改本文件 §3，再改两端代码。
3. **本机优先**：基础输入、学习、剪贴板历史永远本地；网络功能（GY Link / GyenBox）未接入前，所有同步字样都是占位。

## 1. 设置面板契约（5 页，页序固定）

`通用 · 输入 · 外观 · 账户 · 剪贴板`

| 页 | 内容（自上而下） | 控件行为 |
|---|---|---|
| 通用 | 常用短语卡（管理›/完成编辑）→ 工具行：清空学习 · 导出 · 导入 → **跨设备剪贴板开关卡** → **即时粘贴开关卡** | 开关拨动即写入（不等"完成"）；清空学习需确认：`清空本机的所有候选学习记录？常用短语不会受影响。` |
| 输入 | 输入语言三段选择（简体/繁体/EN）→ 切换规则卡 → 热启动加速卡 | 热启动文案两行：`开启后引擎保持热连接，按键零等待；关闭后每次按键重新握手。` + `建议 4 核 CPU / 8 GB 内存及以上开启；更低配置的设备请关闭。` |
| 外观 | 候选窗主题 3 张纵向卡（GY 蓝夜/暖白/石墨，带迷你预览）→ 候选字大小三段（紧凑/默认/大）→ AI 外观预览助手卡 | 主题点选即写入即换肤；AI 助手只可建议主题/字号/对比度，**不动 Logo、候选窗箭头、布局、输入交互** |
| 账户 | 本地标识（可编辑）→ GY 账户占位卡 | 占位文案：`同步、跨设备词库和 AI 权益将在账户接入后开放。` |
| 剪贴板 | **纯历史卡片流**：无页头、无标题行；「清空」浮于右上角；每条历史一张圆角卡（内容整段双行铺开 + 时间）；滚轮翻页；页开着时新复制即时上卡 | 清空需确认：`清空本机剪贴板历史？不影响其他设备。` |

面板通则：窗口尺寸固定（Windows 520×680 DIP，Mac 等比）；换页不换壳；开关是唯一即时生效控件；底部「完成」按钮 + `所有基础输入设置仅保存在本机` 说明。

## 2. 输入行为契约

| 行为 | 契约 |
|---|---|
| 输入模式 | 枚举两端一致：`0=简体 1=繁体 2=EN` |
| Shift 快切 | Shift 一键切 EN；若中文预编辑中已有 ASCII 拼音，先原样上屏再切换；**EN 模式下字母、标点、Enter 与快捷键原样直出** |
| EN 生命周期 | **EN 是焦点内的临时状态**：新焦点（切应用/切文档）一律自动回中文并闪模式提示，EN 不再跨应用跟随（2026-08-05 B+C 决策；C 保留、B 大徽章于同日回滚） |
| 模式提示 | 切换时光标旁小条内显模式字（简/繁/EN）**700ms**，不弹大徽章（148×60 大徽章实测过大，已回滚） |
| 候选窗 | 锚定光标/输入点；首帧测量成锚，后续异常测量（跳变 >1.5 行高或横向 >96px）必须钳制，**候选窗永远不许漂移** |
| 翻页 | 长词不锁翻页；面板宽度有 DPI 缩放的上界，溢出用省略号提示，不许无声硬切 |
| 学习 | 本地学习影响候选排序；学习数据**不进**导入导出；词源脏数据（如 `肟`）靠"清空学习"恢复 |

## 3. 设置存储契约（Windows INI ↔ macOS plist）

| 语义 | Windows（`settings.ini`） | macOS（`GYSettingsStore`） | 默认 | 取值 |
|---|---|---|---|---|
| 输入模式 | `[Input] Mode` | `inputMode` | 0 | 0/1/2 |
| 主题 | `[Appearance] Theme` | `candidateTheme` | 0 | 0/1/2 |
| 候选字号 | `[Appearance] CandidateSize` | `candidateFontSize` | 15 | 13/15/17 |
| 热启动 | `[Performance] WarmStart` | `warmStartEnabled`（**待加**） | 1 | 0/1 |
| 跨设备剪贴板 | `[Clipboard] Enabled` | `clipboardSyncEnabled`（**待加**） | 1 | 0/1 |
| 即时粘贴 | `[Clipboard] InstantPaste` | `clipboardInstantPaste`（**待加**） | 1 | 0/1 |
| 本地标识 | `[Account] Name` | `accountName` | 空 | 自由文本 |
| 常用短语 | `[Phrases] code=a\|b` | `customPhrases`（dict） | 空 | 每码多词保序 |
| 学习 | `[Learning]` 段 | Rime userdb | — | **永不入导入导出** |

导入导出：单文件 ≤ 64 KB；导入前先写 `.bak`；仅含上表设置项，**不含学习与剪贴板历史**。

## 4. 剪贴板契约（本机历史 = 未来 GyenBox 入口）

1. **捕获**：系统剪贴板文本监听（Win：`AddClipboardFormatListener`；Mac：`NSPasteboard.changeCount` 轮询，间隔 ≤ 0.5s）。
2. **存储**：最近 **20 条，先进后出**；单条 ≤ **1 MiB**；**连续去重**（与最新一条相同则不入）；一期纯文本。
3. **本机文件**：Win `%LOCALAPPDATA%\GYInput\clipboard-history.tsv`；Mac `~/Library/Application Support/GYInput/clipboard-history.tsv`——**格式相同**（`unix时间 \t 文本` 转义行），为未来互同步打底。
4. **呈现**：卡片流（一条复制 = 一张卡）。⚓ 此形态是 **GyenBox 绑定的产品锚点**，可微调样式，不可推翻形态（见 `CLIPBOARD-PAGE-DESIGN.md`）。
5. **清空**：两端同一确认文案；清空只删本机文件，不碰其他设备。
