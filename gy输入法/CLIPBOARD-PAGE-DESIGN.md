# GY 设置面板 · 剪贴板页设计规范（GY Link 跨设备剪贴板）

> 版本：2026-08-05 · 产品决策已确认 · 上位文件：`GY_LINK_CLIPBOARD_SPEC.md`、`SETTINGS-PANEL-DESIGN.md`
> **本页是会员层（GY Link Agent）的设置界面**。Agent 未上线前，本页开关真实写入设置存储，同步状态区显示"待账户接入"。

## 0. 本轮产品决策（覆盖规格默认值，已确认）

| 决策 | 值 | 说明 |
|---|---|---|
| 即时粘贴 | **默认开启** | "只要我复制了，就默认粘贴上去"——覆盖 GY_LINK_CLIPBOARD_SPEC 的"受保护同步默认" |
| 历史容量 | **20 条** | 本地剪贴板历史 |
| 淘汰规则 | **先进后出（FIFO）** | 第 21 条进来，最旧一条出局 |
| 内容类型 | **纯文字**（一期），URL/富文本随后 | 图片/文件二期 |
| 单条大小 | **标准大小 1 MiB** | 超限不入历史、不同步 |

### v3 布局决策（2026-08-05 第二轮，已确认并落地）

- **两个开关挪到"通用"页**：「跨设备剪贴板」与「即时粘贴」两张开关卡挂在通用页工具行（清空学习/导出/导入）之下，拨动即写入。
- **剪贴板页只留历史**：页内为纯卡片式历史流——无页头、无标题行，「清空」浮于右上角；每条历史一张圆角卡片（内容整段双行铺开 14pt + 时间，76px 卡高、88px 步距），滚轮翻页。
- 下文 §2 的卡片 1/2 描述仍适用于开关本身（文案/默认/视觉不变），仅位置改到通用页；卡片 4/5 已从页面移除。

### ⚓ 产品锚点（2026-08-05 确认，勿动）

- **本机历史卡片流是 GyenBox 绑定的占位**。这 20 条本机历史将来就是 GyenBox "keep notes" 在输入法侧的入口——卡片视觉语义（一条复制 = 一张卡）与 GyenBox 的卡片流一一对应，跨端同步接通后本页直接映射 GyenBox 数据。**这是重头戏，卡片样式可以微调，"卡片流"形态不要推翻。**

## 3. 视觉规则

- 全部复用 SETTINGS-PANEL-DESIGN §8 的三主题 palette（ink/surface/border/text/muted/accent），**不新增颜色**
- 卡片：圆角 9、surface 底、border 描边、内边距 16、卡片间距 14
- 开关尺寸：44×26（设计 px），滑钮直径 20，滑动动画 120ms  ease-out
- 开关=页面内唯一的即时生效控件：**拨动即写入设置存储**（不等"完成"按钮），与"输入页三段选择器"同契约
- 窗口尺寸不变（520×680），切到本页不跳

## 4. 数据契约

```text
Clipboard.Enabled       = 0|1   跨设备剪贴板（默认 1）
Clipboard.InstantPaste  = 0|1   即时粘贴（默认 1，本产品决策）
Clipboard.HistoryLimit  = 20    固定值，一期不暴露修改
Clipboard.MaxItemBytes  = 1048576  固定 1 MiB
```

历史条目结构（供 Agent 实现）：`{ id, 来源设备, 时间戳, 类型, 内容, TTL }`；写入远端内容必须带 `GYLink.Origin` 标记防同步环（见 GY_LINK_CLIPBOARD_SPEC）。

## 5. 红线（继承规格，不得违反）

- 输入法 TSF/引擎进程**零网络**；同步由常驻 Agent 执行
- 敏感内容（验证码/密码/私钥/银行卡）默认仅本机
- 端到端加密，中继只见密文；删除设备即轮换密钥
- 关闭即时粘贴后，远端内容**绝不**改写本机系统剪贴板
