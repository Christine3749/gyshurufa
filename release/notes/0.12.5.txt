0.12.5 — ThinkPad 中文输入恢复候选版

本版本只修复 0.12.4 在 ThinkPad 重启后可能只剩英文、没有 GY 中文候选框的问题；候选窗外观与 0.12.4 保持一致，不在这一版同时修改其他输入行为。

升级修复：
- 正常升级不再先注销 GY 的 Windows 文本服务配置，保留当前账户已经启用的 GY 输入法。
- 只有真正卸载时才允许注销 GY 配置，避免升级后退回 Windows ENG。
- 重启后的当前账户键盘恢复改为“验证成功后才结束”；如果启动顺序较慢，会在后续登录继续补全，而不是失败一次后永久放弃。
- 写入键盘列表后立即回读确认 GY 已被 Windows 保留，未确认成功就不清除恢复任务。

ThinkPad 验收重点：
- 安装后正常重启一次。
- 使用 Win + Space 选择 GY，任务栏应显示 GY / 简，而不是 Windows ENG。
- 在普通记事本输入 woshi，应出现中文候选并可输出“我是”。
- 再切到 EN 输入 woman5，确认英文和数字仍可原样输入。
