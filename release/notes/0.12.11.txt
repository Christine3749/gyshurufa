GY 输入法 Windows 0.12.11 激活与 Host 双重自恢复候选版

- 0.12.10 因实机发现重启后 ONSTART 激活任务消失，导致文件和 Host 已是新版、TSF 注册仍停在 pending，现已永久跳过，禁止重建或覆盖。
- 待激活事务同时注册延迟 ONSTART 与 ONLOGON 系统任务；两者都必须通过 BootId 变更校验，登出/登入不能绕过重启边界。
- 新版 TSF 在激活预热发现旧 Host 时，只启动独立一次性协调进程；协调进程核对机器注册路径与版本后，通过 GY 私有协议请求旧 Host 正常退出，不强制结束浏览器、Word 或任何用户应用。
- 长时间运行的旧 DLL 若看到注册表已指向新版，会保持失败关闭，不能反过来终止新 Host。
- 新增隔离管道回归：启动一个报告旧版身份的 Host，验证新协调器能优雅交接并恢复候选查询。
- 保留 Firefox / Chromium 地址栏直接英文策略、Windows 开始菜单搜索中文管道，以及不记录用户文本的 TSF 生命周期诊断。
- 本候选版仅供 Ethan 的 ThinkPad 真实应用验收；验收完成前不进入稳定版通道。
