GY 输入法 Windows 0.12.7 Firefox 地址栏候选版

- 0.12.6 在公开发布前因产生多个候选哈希而永久撤回；本版本使用新的不可复用版本号。
- 增加不记录输入文本的 TSF 生命周期诊断日志，用于关联 Firefox 地址栏的
  document manager、ITfContext、异步 edit session、组合对象与 InputScope 时序。
- 保留已接受的异步组合生命周期编辑，并在 URL 输入域迟到时按原文结束首字母组合。
- TSF 核心只接受同一 0.12.7 版本、同一协议的候选 Host；缺失版本信息或旧 Host
  不再被当作兼容对象，避免“显示简体、候选实际来自旧版繁体状态”。
- 本版本仅用于 ThinkPad 真实应用验收；不替换 0.12.5，也不改动稳定版通道。
